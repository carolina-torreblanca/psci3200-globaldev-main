What is Quarto?

Quarto is a publishing system that lets you combine text, code, and output into a single document.

Why use Quarto?

  • Write analysis and explanation in one place
  • Code runs and updates automatically when you render
  • Export to HTML, PDF, Word, slides, websites
  • All your assignments will be .qmd files rendered to .html
  • Your final project will be a Quarto website

The workflow:

  1. Write text and code in a .qmd file
  2. Click “Render” (or Ctrl+Shift+K)
  3. Quarto runs your code and produces a polished document

Quarto Basics

The YAML Header

Every Quarto document starts with a YAML header between --- marks:

---
title: "My Analysis"
author: "Your Name"
date: today
format: html
---

This controls the document’s metadata and output format.

Markdown Formatting

Quarto uses Markdown for text formatting:

  • italics with *italics*
  • bold with **bold**
  • links with [text](url)
  • Create sections with #, ##, ###

Lists

Bullet points:

  • First item
  • Second item
  • Third item

Numbered lists:

  1. First step
  2. Second step
  3. Third step

Math

Use LaTeX for equations. Inline math: \(y = mx + b\)

Display equations:

\[ \bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i \]

Code in Quarto

The real power of Quarto is integrating code with your writing.

Code Chunks

Insert R code in “chunks” that look like this:

```{r}
# Your R code here
mean(c(1, 2, 3, 4, 5))
```

When you render, the code runs and the output appears in your document.

Example: Running Code

# This code will run when you render
x <- c(10, 20, 30, 40, 50)
mean(x)
[1] 30

Chunk Options

Control how chunks behave with options:

#| echo: true       # Show the code in output
#| echo: false      # Hide the code, show only results
#| eval: false      # Show code but don't run it
#| warning: false   # Suppress warning messages
#| message: false   # Suppress messages

Inline Code

Reference values directly in your text using inline code.

n_cars <- nrow(mtcars)
avg_mpg <- round(mean(mtcars$mpg), 1)

Write: “The dataset contains `r n_cars` cars with an average fuel efficiency of `r avg_mpg` mpg.”

Result: The dataset contains 32 cars with an average fuel efficiency of 20.1 mpg.

If your data changes, these numbers update automatically!

Rendering Your Document

To create the final output:

  1. RStudio: Click the “Render” button or press Ctrl+Shift+K
  2. Terminal: Run quarto render yourfile.qmd

The output (.html, .pdf, etc.) appears in the same folder.
